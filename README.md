# KAI CASINO X

Premium Android casino-style entertainment demo.

## Included
- Original KAI CASINO X logo and dark premium UI
- Persistent demo-credit wallet (starts at 10,000)
- Blackjack demo table
- European Roulette red/black demo
- Original KX 3-reel slots
- Demo-wallet reset/control center
- Android-first portrait layout
- GitHub Actions APK build and automatic v1.0.0 release

## Safety / product scope
KAI CASINO X uses virtual demo credits only. There is no deposit, withdrawal, cash-out, purchasable gambling balance, or real-money wagering.

## Build
`gradle :app:assembleDebug`

APK output: `app/build/outputs/apk/debug/app-debug.apk`
